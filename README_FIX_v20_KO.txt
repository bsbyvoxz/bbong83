폴라 혼탑 v20 / F3 우선 수정본 (AutoHotkey v1.1 + Python)

확인된 원인:
1. 게임 HUD 버프 인식 실패를 유효한 미적용으로 취급하여 F1,F2,F6,F7을 7초 간격으로 계속 재시전함.
2. 버프가 대기열에 있거나 현재 슬롯이 2이면 F3 공격 타이머가 통째로 건너뛰어짐.
3. F3 MP 변화 미확인 시 1.5초 후 재시도로 10.25초 타이머를 리셋해 실제 공격 주기가 늘어남.

수정 사항:
- 해머휠 시간이 되면 버프 대기열이 있더라도 1번 슬롯으로 전환하여 F3 우선 사용.
- 시작 후 버프 4개는 연속 시전. 이후 이미 쓴 버프는 아이콘이 보였었다가 사라진 것이 확인되거나 285초 가까이 지난 경우만 갱신.
- F3 실패 추정에 의한 이른 중복 재시도 제거. 다음 F3 주기는 10.25초 기준.
- F3 지연이 1.6초 이상이면 F3 DELAY 로그로 원인 추적.
- 기존 몬스터 추적, 동전 Z 줍기, HP50%, MP40%, 위험 지형 보수적 회피는 이전 버전 유지.

실행: 구 버전 종료 -> SETUP.bat(최초에만) -> START.bat -> F9 위치 -> F10 시작.
기존 게이지 보정이 없으면 Ctrl+F9로 네 지점 등록해야 함.
F8 이동 토글, F11 정지, F12 종료.

주의: 이 파일은 코드 구문 검사와 오프라인 조건 테스트를 거친 수정본입니다. 실제 포푸리 서버에서 입력 성공/항상 안전한 이동은 검증되지 않았습니다.
게임 서버의 자동화 사용 규정에 따르세요.
